# 无人机轨迹平滑与通信优化项目

## 1. 项目概述

本项目旨在优化无人机（UAV）的飞行轨迹，以便为地面上的多个物联网（IoT）设备提供高效的无线通信服务。项目集成了多种先进技术，包括用于信道预测的深度学习、用于轨迹控制的强化学习以及用于数据增强的生成对抗网络（GAN）。核心目标是使无人机能够在最短的时间内完成数据采集任务，同时保持可靠的通信链路。

## 2. 核心组件

项目主要由三个核心部分构成：信道知识地图（CKM）、强化学习（RL）智能体和自定义的仿真环境。

### 2.1. 信道知识地图 (CKM)

CKM 是一个深度学习模型，旨在预测无人机与地面用户之间的无线信道增益。这一预测功能对于强化学习智能体做出明智决策至关重要。

-   **功能**：基于无人机、用户的三维位置以及详细的三维环境数据（如建筑物、植被等），预测信道增益。
-   **数据处理**：`CKM/` 目录下的脚本（如 `conEnv.py` 和 `load_data.py`）用于处理来自仿真软件（如 Wireless Insite）的原始环境数据和信道测量数据，并将其转换为可用格式。
-   **模型训练**：`CKM/mixed_CKM.py` 和 `CKM/convCKM.py` 用于训练神经网络。该模型学习物理环境与无线电波传播之间的复杂关系。
-   **输出**：训练好的 CKM 模型被保存为 `.h5` 文件，随后加载到仿真环境中，以提供实时的信道预测。

### 2.2. 强化学习智能体

轨迹优化的核心是一个强化学习智能体，它通过学习为无人机找到最优的控制策略。

-   **算法**：项目采用了当前最先进的强化学习算法，特别是近端策略优化（PPO）和优势演员-评论家（A2C），这些算法通过 `stable-baselines3` 库实现。
-   **训练**：训练过程由 `train/` 目录下的脚本处理，例如 `train_ppo.py` 和 `train_AC.py`。在训练期间，智能体与自定义的仿真环境互动，学习一个能够最大化累积奖励信号的策略。
-   **目标**：智能体的目标是找到一条能够最小化任务完成时间并确保所有地面设备都得到服务的轨迹。奖励函数的设计旨在激励效率和任务的完成。
-   **评估**：训练好的模型使用 `evaluate/` 目录下的脚本（`evaluate_ppo.py`、`evaluate_AC.py`）进行评估。这些脚本会运行智能体多个回合，并报告平均奖励和任务用时等性能指标。

### 2.3. 无人机 Gym 环境

项目构建了一个遵循 OpenAI Gym 接口的自定义仿真环境，为强化学习智能体的训练和测试提供了平台。

-   **代码位置**：环境代码位于 `uav_gym/envs/uav_env.py`。
-   **状态空间**：代表智能体做出决策所需的所有信息，包括无人机的位置、速度、所有物联网设备的位置及其当前的通信状态。
-   **动作空间**：定义了无人机可以采取的可能动作，例如调整速度、改变方向（水平和垂直）以及分配发射功率。
-   **奖励函数**：一个精心设计的奖励函数引导智能体的学习过程。它为完成通信任务提供正向奖励，并对浪费时间或能源、或违反约束（例如飞出边界）的行为进行惩罚。
-   **与 CKM 集成**：该环境在每一步都动态调用预训练的 CKM 来预测信道条件，使仿真更加真实，并帮助智能体学习到更鲁棒的策略。

### 2.4. 数据增强 (GAN)

为了提高需要大量数据的 CKM 的准确性，项目采用了一个条件生成对抗网络（cGAN）。

-   **功能**：`GAN/` 目录中的脚本，特别是 `cGAN.py`，用于训练一个能够生成合成信道数据的模型。
-   **目的**：这些模拟真实数据统计特性的合成数据被用来扩充 CKM 的训练集，帮助其更好地泛化并做出更准确的预测。

## 3. 文件结构与说明

```
.
├── CKM/               # 信道知识地图：数据处理与模型训练
├── evaluate/          # 用于评估已训练的强化学习模型的脚本
├── GAN/               # 用于数据增强的 cGAN
├── train/             # 强化学习智能体训练脚本 (PPO, A2C)
├── uav_gym/           # 用于无人机仿真的自定义 OpenAI Gym 环境
├── requirements.txt   # 项目依赖
└── ...                # 其他数据文件、日志和图表
```

-   **`CKM/`**: 包含处理环境数据、训练信道预测模型及相关工具的脚本。
-   **`train/`**: 强化学习训练脚本的主要存放目录。通过配置并运行这些文件来训练 PPO 或 A2C 智能体。
-   **`evaluate/`**: 使用此处的脚本加载预训练的智能体，并在仿真环境中评估其性能。同时包含用于结果可视化的绘图工具。
-   **`uav_gym/`**: 定义了仿真环境，包括物理模型、状态/动作空间和奖励逻辑。
-   **`GAN/`**: 包含了用于生成补充训练数据的 cGAN 的实现。

## 4. 如何使用

1.  **安装依赖**: 使用 `requirements.txt` 文件安装所有必需的 Python 包：
    ```bash
    pip install -r requirements.txt
    ```

2.  **CKM 训练 (可选)**: 如果您有新的环境或信道数据，可以运行 `CKM/` 目录中的脚本来训练新的信道模型。项目中已包含一个预训练好的模型。

3.  **强化学习智能体训练**:
    -   进入 `train/` 目录。
    -   运行 `train_ppo.py` 或 `train_AC.py` 来开始对应智能体的训练过程。
    -   训练进度将被记录，最终模型将被保存（通常为 `.zip` 文件）。

4.  **模型评估**:
    -   进入 `evaluate/` 目录。
    -   修改 `evaluate_ppo.py` 或 `evaluate_AC.py`，使其指向您保存的模型路径。
    -   运行脚本以观察训练好的智能体在仿真环境中的表现，并收集性能统计数据。

## 5. 主要代码文件功能详解

为了更深入地了解项目，以下是各主要 `.py` 文件的功能简介。

### 5.1. `CKM` 目录 (信道知识地图)

该目录包含了构建、训练和评估信道知识地图（CKM）所需的所有脚本。

-   `conEnv.py`: 从仿真软件（如 Wireless Insite）导出的环境文件中提取建筑物等物体的三维坐标。它能够解析特定格式的文本文件，将坐标数据结构化，并以 `.pkl` 和 `.npy` 格式保存，同时可以生成环境的3D可视化图。
-   `load_data.py`: 加载无人机的轨迹点数据 (`tx.npy`) 和对应的信道增益测量值。此脚本将这些原始数据整合成用于训练信道模型的输入特征（用户和无人机的位置坐标）和目标标签（信道增益）。
-   `mixed_CKM.py`: 定义并训练一个基于多层感知机（MLP）的深度学习模型来预测信道增益。该模型融合了无人机/用户位置信息和从`conEnv.py`得到的环境特征。脚本中还包含了数据归一化、添加模拟噪声以测试模型鲁棒性等功能。
-   `convCKM.py`: 与`mixed_CKM.py`类似，但使用卷积神经网络（CNN）来编码环境特征，旨在更好地捕捉环境数据的空间相关性。
-   `train_STU.py`: 实现了知识蒸馏的训练流程。它加载一个已经训练好的、复杂的“教师”模型，并用其输出来指导一个更小、更轻量的“学生”模型的训练，旨在让学生模型在保持较低复杂度的同时，学习到教师模型的性能。
-   `gen_CKM.py` & `update_CKM.py`: 这两个脚本似乎用于生成和更新信道数据，可能是为了数据增强或处理特定场景下的信道信息。
-   `err.py`: 包含一个辅助函数 `add_err`，用于向位置坐标数据中添加符合特定误差半径（CEP）的随机噪声，以模拟定位误差。
-   `eval_CKM.py`: 用于加载一个已经训练好的CKM模型，并使用测试数据对其进行评估，输出预测损失等指标。
-   `try.py`: 一个测试脚本，用于加载训练好的信道模型 (`.h5` 文件)，生成带或不带噪声的样本输入，进行预测，并以图表形式直观地比较预测值与真实值之间的差异。
-   `plot_*.py` (e.g., `plot_gain.py`, `plotCEP.py`, `plot_comp.py`): 一系列用于数据可视化的脚本。分别用于对比不同信道增益数据、可视化CEP定位误差、以及绘制其他对比图表。

### 5.2. `train` 目录 (强化学习训练)

该目录存放了用于训练强化学习智能体的核心脚本。

-   `train_ppo.py`: 使用`stable-baselines3`库中的近端策略优化（PPO）算法来训练无人机智能体。它负责初始化自定义的Gym环境、配置PPO模型（网络结构、学习率等参数）并启动训练流程。训练日志会保存在`tensorboard`目录中，最终模型被保存为`.zip`文件。
-   `train_AC.py`: 与`train_ppo.py`功能类似，但使用的是优势演员-评论家（A2C）算法进行训练。
-   `train_Bezier.py`: 尝试使用贝塞尔曲线来生成更平滑的无人机轨迹。它将强化学习的动作输出作为贝塞尔曲线的控制点，从而优化轨迹的平滑度。
-   `MyLogger.py`: 一个简单的日志记录工具类，可以将所有打印到控制台的输出（`stdout`）重定向到一个指定的日志文件中，方便后续分析。
-   `KDML_CKM.py`: 包含一个`calculate_path_loss`函数，这个函数似乎是CKM模型的另一种实现或一个简化版本，用于在特定情况下计算路径损耗。
-   `plot_rewards.py`: 用于读取训练过程中保存的奖励日志文件，并绘制奖励随训练回合数变化的曲线图，以监控训练效果。

### 5.3. `evaluate` 目录 (模型评估)

此目录下的脚本用于评估已训练好的强化学习智能体的性能。

-   `evaluate_ppo.py` & `evaluate_AC.py`: 分别加载预训练的PPO和A2C模型，在仿真环境中运行指定的评估回合数。脚本会记录并输出平均奖励、任务完成时间、成功率等关键性能指标。
-   `plot_*.py` (e.g., `plot_eval.py`, `plot_los.py`, `plot_rewards.py`): 一系列用于可视化评估结果的脚本。例如，绘制无人机飞行的3D轨迹图、展示与地面设备的通信状态变化、或绘制每个评估回合的奖励曲线。

### 5.4. `GAN` 目录 (数据增强)

此目录存放了用于生成对抗网络（GAN）的相关代码，主要用于数据增强。

-   `cGAN.py`: 实现了一个条件生成对抗网络（Conditional GAN）。它定义了生成器和判别器的网络结构以及训练逻辑。通过输入特定的条件信息（例如无人机和用户的位置），网络可以生成符合该条件的、逼真的信道增益数据。
-   `enlarge_data.py`: 使用已经训练好的cGAN模型来生成大量的合成数据，以扩充现有的信道数据集。
-   `evaluate_gen.py`: 用于评估GAN生成数据的质量，例如通过统计分布或可视化来比较生成数据与真实数据之间的相似性。
-   `比较仿真数据和LOS.py`: 一个中文命名的脚本，功能是对比分析仿真生成的信道数据和一个简化的视距（Line-of-Sight, LOS）模型之间的差异。

### 5.5. `uav_gym` 目录 (仿真环境)

这是定义无人机仿真环境的核心目录。

-   `envs/uav_env.py`: 实现了遵循OpenAI Gym标准的无人机仿真环境。
    -   `UavConfig` 类: 集中管理了所有仿真相关的参数，如场景尺寸、无人机最大速度、通信频率、功率等。
    -   `uavEnv` 类: 实现了Gym环境的核心接口，包括 `reset` (重置环境到初始状态) 和 `step` (执行一个动作并返回新状态、奖励、是否完成等信息)。它还定义了复杂的状态空间、动作空间和核心的奖励函数。该环境在内部加载并调用CKM模型来模拟真实的信道变化。
-   `envs/uav_env1.py`: 可能是`uav_env.py`的一个变体或用于不同实验阶段的另一个版本的环境。
